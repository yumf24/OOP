架构设计：游戏技能系统

在 RPG 游戏中，角色的“技能释放系统”是核心模块之一；随着游戏版本的迭代，我们不仅需要接入一些早期遗留的法术代码，还需要在角色释放技能时进行法力值（MP）的扣除校验，甚至要能动态地给技能附加各种增益状态（Buff）。为了保证游戏代码的极高可维护性，现要求你使用面向对象的设计模式（适配器、代理/委托、装饰器）来重构技能系统的底层架构。

系统需求

技能基类

系统需要一个统一的技能抽象基类 ISkill，包含一个纯虚函数 int cast();，用于释放技能并返回该技能造成的最终基础伤害值；为了避免内存泄漏，大家应实现一个虚析构函数。

兼容上古代码

我们从十年前的老游戏引擎里直接拷来了一个特别好用的上古法术类 LegacySkill，但它没有继承任何接口，且释放法术的成员函数为 int doMagicAttack();。

任务：请设计一个新类 LegacySkillAdapter，通过组合这个老类，将其接口转换与现代的 ISkill 一致的接口，让我们的新框架可以无缝调用它。

法力值（MP）校验系统

释放技能不是无限制的。我们在真正让法术生效前，必须检查角色的状态。

任务：请设计一个新类 MpChecker，它同样实现 ISkill 接口。它在内部持有一个真实的 ISkill 指针，并记录该技能每次释放需要的法力消耗（mpCost），以及角色当前的剩余法力值，可以在代理类内部维护一个 currentMp 变量。

  • 在 MpChecker 初始化时，应接受三个参数：ISkill 指针，即需要检查的技能；mpInit，即角色初始的 MP 值；mpCost，即技能每次释放所需要扣除的 MP 值；
  • 在调用 cast() 时，代理需要先判断 currentMp 是否大于等于 mpCost。
  • 如果充足，则扣除相应 MP，并调用真实技能的 cast() 放行。
  • 如果不足，则直接拦截释放，并在控制台输出 "[MP insufficient!]"，随后返回伤害值 0。

动态技能增益

在不修改基础技能代码的前提下，我们需要能给技能动态套上各种 Buff，这里大家实现两种即可：

  • 暴击增益（CritBuff）：将技能造成的最终伤害翻倍（原伤害 * 2），并在输出伤害前打印 [Critical hit!]。
  • 淬毒增益（PoisonBuff）：在技能原伤害基础上额外增加 15 点毒属性固定伤害（原伤害 + 15），并在输出前打印 [Poison hit!]。

任务：请设计实现上述两个具体的 Buff 类（可以引入其他辅助类），它们必须能够层层嵌套，比如让一个火球术既能暴击又能带毒；注意，Buff 叠加顺序严格由嵌套顺序决定，如原始伤害为 10，先套暴击，再套毒（即 PoisonBuff(CritBuff(skill))），则最后伤害为 (10 * 2 + 15)；同一种 Buff 可以被重复叠加。

  1. 供大家测试用的 main.cpp：
#include <iostream>
#include "LegacySkill.h"
// 类和接口的声明都在 GameSkill.h 中
#include "GameSkill.h"

int main() {
    std::cout << "--- Game Skill System Test Start ---\n\n";

    // 1. 实例化上古技能 (Legacy Engine)
    LegacySkill* legacySkill = new LegacySkill();

    // 2. 将上古技能转换为 ISkill 接口
    ISkill* adapter = new LegacySkillAdapter(legacySkill);

    // 3. 叠加毒属性 Buff (+15 伤害)
    ISkill* poisonedSkill = new PoisonBuff(adapter);

    // 4. 叠加暴击 Buff (伤害 * 2)
    // 注意：嵌套顺序为 Crit(Poison(Adapter))
    ISkill* ultimateSkill = new CritBuff(poisonedSkill);

    // 5. 加入 MP 校验系统
    // 设定角色初始 MP 为 50，该技能每次释放消耗 20 MP
    ISkill* systemProxy = new MpChecker(ultimateSkill, 50, 20);

    // 第一次释放（此时 MP=50，充足）
    std::cout << ">> Cast 1:" << std::endl;
    int dmg1 = systemProxy->cast();
    std::cout << "Final Damage: " << dmg1 << "\n\n";

    // 第二次释放（此时 MP=30，依然充足）
    std::cout << ">> Cast 2:" << std::endl;
    int dmg2 = systemProxy->cast();
    std::cout << "Final Damage: " << dmg2 << "\n\n";

    // 第三次释放（此时 MP=10，不足，触发代理拦截）
    std::cout << ">> Cast 3:" << std::endl;
    int dmg3 = systemProxy->cast();
    std::cout << "Final Damage: " << dmg3 << "\n\n";

    // 内存清理（大家务必记得实现虚析构函数）
    delete systemProxy;
    
    std::cout << "--- Game Skill System Test End ---\n";
    return 0;
}
